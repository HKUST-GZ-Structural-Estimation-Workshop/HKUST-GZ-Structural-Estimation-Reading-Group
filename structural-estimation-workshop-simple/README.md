# HKUST(GZ) Structural Estimation Workshop

Private repository for the workshop.

The workshop focuses on learning structural estimation by connecting economic models, data, numerical methods, and reproducible implementation.

## Repository Structure

Each week has three folders:

- `slides/` — presentation PDF and LaTeX source
- `papers/` — assigned and related readings
- `tutorials/` — code, toy data, notebooks, exercises, and replication materials

Example:

```text
week04_discrete_choice_demand/
├── slides/
├── papers/
└── tutorials/
```

## Workflow

Before each session:

1. Upload the presentation PDF and `.tex` files to `slides/`.
2. Upload assigned readings to `papers/`.
3. Upload tutorial notebooks, code, toy data, or replication material to `tutorials/`.
4. Update `schedule.md` if the presenter, date, or topic changes.

## Note on Data

Please do not upload large or confidential raw datasets to the repository.  
For large datasets, add a short README or text file in `tutorials/` describing the data source and how to access it.
